## 快速上手

1. 启动后在起始页选择最近项目，或把包含动画文件的文件夹拖入窗口，也可以点击「打开文件夹」。
2. 左侧默认勾选全部文件，右侧画布实时播放；取消不需要的文件，或勾选多个文件并排预览。
3. 双击卡片进入全屏，按 `Esc` 返回。

## 主要功能

- **多文件同屏**：自动排布卡片网格，支持滚动、缩放与平移；左侧文件列表可收起。
- **全屏查看**：默认 100% 原始尺寸，按 `F` 适应窗口，滚轮缩放、拖动平移。
- **标签与筛选**：右键卡片添加标签，顶栏可按多个标签同时筛选，搜索框按文件名过滤；文件夹或文件名中的 `[标签]` 会自动成为路径标签。标签库支持新建、改名、删除、复制和粘贴。
- **批量切换**：多选卡片后，可批量切换所选卡片共同拥有的动画或皮肤。
- **截图**：按当前选择导出全部已勾选卡片或所选卡片的长图；右键单张卡片可保存图片或复制到剪贴板。
- **项目记忆**：标签库、卡片标签、卡片大小、动画与皮肤选择自动保存到当前项目；勾选与筛选状态不保存。
- **其他**：起始页保留最近 6 个项目；启动后自动检查更新。

## 常用操作

| 操作 | 功能 |
| --- | --- |
| 双击卡片 / `Enter` | 全屏预览，`Esc` 返回 |
| `空格` | 播放 / 暂停 |
| `F` | 适应画布 / 窗口 |
| 滚轮 / `Ctrl` + 滚轮 | 垂直平移 / 缩放 |
| 右键卡片 / 文件 | 标签、浏览所在文件夹；卡片可截图、复制 |
| `Ctrl` + `O` | 打开其他文件夹 |

## 常见问题

**某些文件无法预览？** 请确认文件完整，并与配套文件放在同一目录；仍无法预览请联系技术支持。

**动画不动？** 只有已勾选的文件会播放；若按钮显示播放三角形，按 `空格` 继续。

**截图保存在哪里？** 长图保存在当前项目文件夹；单张卡片保存在动画文件所在子文件夹（`SpineView.jpg`，每次覆盖）。
